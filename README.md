## 📖 Overview

**VideoHub** is a video streaming platform front-end project. It provides a YouTube-inspired interface for browsing and watching videos with categories, search, and video player functionality.

> 🎯 **Purpose:** Front-end project demonstrating video platform UI development

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎬 **Video Player** | Embedded video playback |
| 📂 **Categories** | Browse videos by category |
| 🔍 **Search** | Search for videos |
| 📱 **Responsive** | Mobile-friendly design |
| 🎨 **Modern UI** | Clean, platform-inspired design |

---
